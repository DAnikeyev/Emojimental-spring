# Emojimental 🌸

Emojimental is a Blazor WebAssembly incremental game about bringing the warm spring. 

The game features a minimalist UI where most information is conveyed through emojis and numbers. Manage resources, research new technologies, and build your factory to transform a frozen world into a blossoming garden.

## Features 🌟

- **Emoji-Driven UI**: Letter characters are avoided in the main game interface, using 🌸, ⚡, ❄️, and other symbols instead.
- **Resource Management**: Collect Energy, Ice, Water, Wood, and more to progress.
- **Incremental Growth**: Upgrade your nodes and research to increase efficiency.
- **Atmospheric Experience**: Dynamic day/night cycles and procedural elements.

## Development 🛠️

This project is built with:
- **Blazor WebAssembly** (.NET 10)
- **BreakInfinity.cs** for handling large numbers

### Build and Run

To build the project:
```powershell
dotnet build
```

To run the project:
```powershell
dotnet run --project Emojimental
```
